# Модули проекта

Уже реализованы:

- `metrics.py` - официальная RMSRE для массивов и словарей с ID растений;
- `download.py` - загрузка, контрольные суммы и проверенная распаковка архива;
- `data.py` - таблица растений, проверка файлов, единиц и битности изображений;
- `splits.py` - создание и повторное чтение неизменных списков holdout/CV;
- `__init__.py` - доступ к метрике через `from tomato_rgbd import rmsre`.

Следующие модули будем добавлять отдельными шагами:

| Модуль | Назначение |
|---|---|
| segmentation.py | Маски зелёных частей и красных плодов |
| features.py | Вычисление входных признаков |
| baseline.py | Простые регрессоры и кросс-валидация |
| geometry.py | Глубина в метрах, облако точек и метрические признаки |
| dataset.py | Загрузка и совместные преобразования RGB-D для сети |
| models.py | ResNet18 RGB и RGB-D |
| train.py | Обучение и сохранение моделей по фолдам |
| evaluate.py | Оценка прогнозов и отчёты об ошибках |

Модуль - отдельный файл с одной понятной обязанностью. Не создаём пустые реализации:
появление модуля в истории должно соответствовать работающему проверенному шагу.
