# Настройки экспериментов

`protocol.json` фиксирует согласованный протокол: seed=42, 20% holdout,
пять фолдов CV, имена и единицы четырёх целей, ожидаемые пути файлов.

`scripts/prepare_data.py` читает эти настройки и проверяет официальные единицы целей.
После первого успешного запуска реальные ID сохраняются в splits/. Менять seed или
данные и молча пересоздавать эти списки запрещено. Настройки обучения добавим
вместе с соответствующим кодом.

Seed — начальное состояние генератора случайных чисел. Его фиксация помогает
повторить разбиение; дополнительно сохраним конкретные ID растений и версии пакетов.
Пути считаются относительно корня проекта, поэтому проект можно перемещать.
