# Зафиксированные разбиения растений

Здесь после аудита данных появятся:

- `holdout.csv` — ID отложенных растений;
- `cv_folds.csv` — ID остальных растений и номер validation-фолда;
- `metadata.json` — seed, версии инструментов и сведения об исходной таблице.

Holdout — 20% растений для единственной финальной проверки. Фолд — одна из пяти
групп кросс-валидации на оставшихся данных. Все изображения одного растения
должны попасть вместе в одну часть.

Списки ID будут храниться в Git и использоваться повторно. Сейчас разбиение
ещё не создано: сначала нужно проверить файлы, уникальность растений и метки.
