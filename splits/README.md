# Зафиксированные разбиения растений

После аудита данных сохранены:

- `holdout.csv` - ID отложенных растений;
- `cv_folds.csv` - ID остальных растений и номер validation-фолда;
- `metadata.json` - seed, версии инструментов и сведения об исходной таблице.

Holdout - 20% растений для единственной финальной проверки. Фолд - одна из пяти
групп кросс-валидации на оставшихся данных. Все изображения одного растения
должны попасть вместе в одну часть.

Списки ID хранятся в Git и используются повторно: 96 растений holdout и 383
development. Номер fold от 0 до 4 указывает validation-группу, остальные
development-строки используются для обучения в этом запуске.

`metadata.json` фиксирует seed=42, распределение сортов и контрольные суммы.
Повторный запуск не меняет списки; изменения файлов или протокола вызывают ошибку.
В этих CSV нет значений высоты, массы, площади листьев или числа плодов.
Итоги: [отчёт о подготовке](../reports/data_preparation.md).
