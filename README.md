# Предсказание признаков томата по RGB-D

Учебный проект по оценке высоты, сырой массы, площади листьев и числа полностью
красных плодов по изображениям 479 растений карликового томата.

Репозиторий: [OverLordic/tomato-rgbd](https://github.com/OverLordic/tomato-rgbd).
Задача включает baseline на вычисленных признаках, ResNet18 RGB/RGB-D, геометрию
облака точек и оценку переноса на новый сорт по официальной метрике RMSRE.

Работа выполняется небольшими воспроизводимыми шагами. Используется помощь AI;
объяснения модулей и проверки расчётов входят в проект, чтобы автор мог разобрать
и защитить код самостоятельно.

## Требования и порядок работы

1. Проверить данные и единицы измерения, создать таблицу растений.
2. Один раз отложить 20% растений со стратификацией по сорту. На остальных 80%
   подбирать модели с пятифолдовой кросс-валидацией.
3. Реализовать официальную RMSRE и baseline на признаках без нейросетей.
4. Сравнить предобученную ResNet18 на RGB и RGB-D.
5. Проанализировать ошибки и пользу глубины, добавить метрическую геометрию.
6. Проверить перенос на новый сорт и выполнить единственную финальную оценку holdout.

Основные входы моделей — изображения. Измеренные ответы не используются как входы.
Сорт нужен для разбиения и анализа, но не является признаком основной модели.
Тестовые растения не участвуют в выборе порогов, параметров и вариантов обучения.

## Данные и источники

Датасет: Righini et al. (2024), **4th Autonomous Greenhouse Challenge: Pre-trial
Dwarf Tomato Measurements and Images**, версия 1,
[DOI](https://doi.org/10.4121/e1ee9de9-6ce9-4502-a37c-34b5b1372bed.v1),
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Нужен архив `4th_autonomous_greenhouse_challenge_dwarf_tomato_pretrial_single_plant_cam.zip`
с [официальной страницы](https://data.4tu.nl/datasets/e1ee9de9-6ce9-4502-a37c-34b5b1372bed).
Размер архива — 7 456 535 483 байта. Полные изображения и веса моделей в Git не входят.
CNN будем обучать в Google Colab или Kaggle; документацию и небольшие проверки
можно выполнять без GPU.

## Запуск первой проверки

Нужен Python 3.10 или новее. Из корня проекта:

```bash
python -m pip install -e .
python -m unittest discover -s tests -v
python examples/metric_demo.py
```

Обе проверки можно выполнить одной командой: `python scripts/check_project.py`.

Пример использует два искусственных растения и не требует скачивания данных.
Ожидаемая RMSRE числа плодов — `0.790569`, общий score — `0.197642`.
Подробный разбор: [RMSRE](docs/learning/02-rmsre.md).
Сведения о выполненной проверке: [отчёт](reports/metric_validation.json).
