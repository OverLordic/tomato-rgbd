# Результаты и проверки

`metric_validation.json` описывает уже выполненные проверки RMSRE на искусственных
примерах. Это проверка кода, а не измерение качества модели на растениях.

Позже здесь будут компактные таблицы качества, графики и разбор ошибок.
Для каждого опыта сохраняем конфиг, версии окружения, используемое разбиение,
прогнозы и оценки по каждой цели. Большие временные файлы помещаем в outputs/,
который исключён из Git.

Итоговые результаты holdout добавляем только после завершения выбора моделей.

Уже добавлены `data_audit.json` и `data_preparation.md`: проверка архива,
1916 PNG, таблица 479 растений и зафиксированные holdout/CV. Статистики целевых
измерений рассчитаны только по development. Это аудит данных, а не оценка модели.

`development_rgb_depth.png` показывает по одному development-растению каждого сорта:
RGB, глубину с фиксированной цветовой шкалой и маску валидной глубины.
Она воспроизводится командой `python scripts/preview_data.py`.
Источник изображений — датасет WUR/4TU, [атрибуция и лицензия](../docs/sources/PROVENANCE.md).
