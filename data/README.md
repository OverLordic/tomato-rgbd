# Данные

- `raw/` — исходный архив и распакованные файлы без редактирования.
- `interim/` — промежуточные маски и проверки изображений.
- `processed/` — таблица растений (manifest) и рассчитанные признаки.

После загрузки ожидаем `raw/single_plant_cam/` с исходными папками train,
validation1, validation2, validation3, test. Это папки соревнования;
собственный holdout создадим отдельно по требованиям задания.

Изображения и производные данные исключены из Git. В историю входят только
это пояснение и пустые `.gitkeep`, которые сохраняют структуру каталогов.
Сейчас изображения ещё не загружены, таблица растений не создана.

Источник и лицензия: [происхождение данных](../docs/sources/PROVENANCE.md).
